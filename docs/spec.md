# spec.md — Техническое задание сайта «Масло Плюс»

> Сеть автосервисов экспресс-замены масла и ТО в Чебоксарах, **3 точки**.
> Полный редизайн старого сайта на WordPress ([masloplus21.ru](https://masloplus21.ru)) → современный, быстрый и безопасный сайт на Next.js 15.
> Ориентир по духу и функциям — [masloff.ru](https://masloff.ru), но **меньше по масштабу**: без личного кабинета, без бонусной программы, без собственного бренда масел, 3 точки вместо 83.

Документ описывает **что** делаем. Модель данных — в [content-model.md](./content-model.md). Правила кода — в [CLAUDE.md](../../CLAUDE.md).

---

## 1. Цели проекта

1. Дать клиенту **прозрачные цены** — ключевая правка (на старом сайте у основных услуг цен не было).
2. **Запись онлайн на самом сайте** (без ухода на сторонний виджет), с возможностью также записаться через Telegram-бот.
3. **Единые и корректные** адреса/телефоны/график (сейчас различаются от страницы к странице).
4. Современный SEO-фундамент: ЧПУ, meta description, Open Graph, JSON-LD (Organization + AutoRepair по точкам) — важно для Яндекса.
5. Живая **галерея работ и видео**, которая обновляется сама из Telegram/VK (владелец не учит новую админку).
6. Скорость (Lighthouse 90+), доступность (a11y) и безопасность (152-ФЗ, security-заголовки, анти-спам форм).

## 3. Что берём у эталона и как масштабируем вниз

**Берём (адаптируем под свой характер, не копия):**

- Каталог услуг категориями с ценами и переключателем «материалы сети / материалы клиента».
- Готовые наборы ТО: авто → тарифы **Бюджет / Оптимум / Премиум** → масло, фильтры, цены операций, итоговая цена; бейджи «Лучший выбор» / «Сохранение гарантии дилера»; фильтр по маркам; блок «Не нашли свою марку».
- Полоса доверия (badges), запись «на сайте / через Telegram», карта точек на Яндексе, юридический подвал.

**Убираем (мы меньше):**

- Личный кабинет / авторизация (`/auth`).
- Бонусная программа и «до 10% бонусов».
- Собственный бренд масел («Продукция Маслофф») — у нас нет своей линейки.
- Разделы «О компании» / «Сотрудничество» как крупные страницы (максимум — короткие блоки).
- Масштаб «83 станции» → честно **3 точки** в Чебоксарах.

**Добавляем своё:**

- Живая галерея видео из Telegram-канала/VK (у эталона такого нет).

## 5. Постраничная спецификация (блоки)

### 5.1. Главная `/`

1. **Hero** — сильный оффер («Замена масла и ТО в Чебоксарах, 3 точки»), CTA «Записаться» + вторичный «Рассчитать стоимость». LCP-изображение с приоритетом.
2. **Полоса доверия** — опыт/стаж, гарантия, «от 15 минут», число точек (3), «оригинальные масла», «более 200 видов масел».
3. **Обзор услуг** — 4 категории с иконками (Двигатель / Фильтры / Трансмиссия / Доп. работы) → ссылки на `/uslugi`.
4. **Готовые наборы ТО** — превью 3–6 популярных карточек → `/nabory`.
5. **«Более 200 видов масел»** — короткий продающий блок.
6. **Галерея работ и видео** — превью → `/galereya`.
7. **Отзывы** — виджет Яндекс.Карт (ленивая загрузка).
8. **Карта** с 3 точками (Яндекс.Карты).
9. **Финальный CTA** «Записаться».

### 5.2. Услуги `/uslugi`

- Каталог по категориям (аккордеон/секции):
  - **Двигатель**: замена масла и масляного фильтра в ДВС; промывка ДВС; замена масляного фильтра без замены масла; выставить уровень масла.
  - **Трансмиссия**: замена масла в АКПП / МКПП / DSG / CVT / раздатке / Haldex / дифференциалах.
  - **Фильтры**: салонный, воздушный.
  - **Доп. работы**: ГУР, тормоза, сцепление, мосты.
  - **Отдельные услуги сети**: проточка тормозных дисков; аппаратная замена антифриза и тормозной жидкости под давлением.
- У каждой услуги — цена или «от N ₽», варианты «материалы сети / материалы клиента».
- **Калькулятор стоимости** (`features/price-calculator`): чекбоксы услуг + переключатель материалов, живой итог, кнопка «Записаться» переносит выбор в форму. Логика — чистые функции + юнит-тесты (Vitest).

### 5.3. Готовые наборы ТО `/nabory`

- Карточки по авто (марка/модель/двигатель/л.с./годы) с тарифами **Бюджет / Оптимум / Премиум**.
- Состав тарифа: заправочный объём, масло, фильтры (масляный/воздушный/салонный), цены операций, **итоговая цена**.
- Бейджи: «Лучший выбор», «Сохранение гарантии дилера».
- **Поиск/фильтр** по марке и модели; чипы популярных марок.
- Блок **«Не нашли свою марку»** — реальная форма заявки на расчёт (не тупик).
- Кнопка «Записаться» переносит выбранный набор в форму.
- Добавление нового авто = добавить объект в `content/packs`, **без правки кода**.

### 5.4. Галерея `/galereya`

- Сетка работ + видео, ленивая загрузка, скелетоны.
- Клик → модалка-лайтбокс с клавиатурной навигацией и корректным a11y.
- Источник — последние посты/видео из Telegram (`t.me/masloplus`) и/или VK (`vk.com/masloplus21`), тянутся **серверно**; токены только в `.env`.
- Видео — embed **только** VK Видео / RuTube (whitelist доменов). Свежесть — ISR/`revalidate` (напр. раз в час).
- Запасной вариант — ручной список в `content/gallery` (описать в README).
- Любые подписи из TG/VK **санитизируются** перед выводом.

### 5.5. Контакты `/kontakty`

- 3 точки: адрес, телефоны (`tel:`), график, ссылки на 2ГИС/Яндекс.Карты — из `content/site.ts`.
- Карта Яндекс с метками всех точек.
- **Форма записи/заявки** (`features/booking`) — см. §6.4.

### 5.6. Юридические `/policy`, `/soglashenie`

- Политика обработки ПД (нужна для чекбокса согласия) и пользовательское соглашение.

## 6. Сквозные функции

### 6.1. Запись онлайн

- Основной путь — форма на сайте (см. §6.4). Дополнительно — кнопка «Записаться через Telegram» (бот/чат).
- Кнопки «Записаться» из калькулятора и наборов **переносят выбор** (услуги/набор/точку) в форму через состояние/query без ПД.

### 6.2. Калькулятор стоимости

- Presentational-часть в `features/price-calculator`; расчётная логика — чистые функции в `lib`, покрытые тестами.

### 6.3. Галерея с видео

- Серверная выборка + ISR; whitelist embed; санитизация; лайтбокс.

### 6.4. Формы (запись/заявка) — безопасно + 152-ФЗ

- Поля: имя, телефон (маска + валидация), точка, услуга/набор (подставляется), комментарий.
- Валидация **zod** и на клиенте, и на сервере.
- **Обязательный чекбокс** согласия на обработку ПД со ссылкой на `/policy`.
- Отправка через серверный API-роут → email и/или Telegram-бот. Секреты только в `.env`.
- Анти-спам: **rate limiting** + **honeypot** + временная ловушка + (по возможности) **Яндекс SmartCaptcha**.
- **Никаких ПД в URL/query и в логах.** Понятные состояния success/error/loading.

### 6.5. Карты и отзывы

- Яндекс.Карты (метки 3 точек) и виджет отзывов Яндекс — ленивая загрузка, чтобы не тормозили.

## 7. Стек и структура папок (из CLAUDE.md)

**Стек:** Next.js 15 (App Router, RSC) · TypeScript strict (`any` запрещён) · Tailwind (токены в `tailwind.config`) · `next/font` c кириллическим subset · контент в `/content` · видео VK/RuTube · Яндекс.Карты · Яндекс.Метрика.

```
src/
  app/                 # роуты (App Router), только композиция
  components/
    ui/                # презентационные (Button, Card, Input…)
    sections/          # секции страниц (Hero, ServicesOverview…)
    layout/            # Header, Footer, Nav
  features/            # фичи с логикой (booking, price-calculator, video-gallery)
  lib/                 # утилиты, api-клиенты, конфиг, zod-схемы
  content/             # контент (JSON/TS/MDX): site, services, packs, gallery
  types/               # общие типы
  hooks/               # переиспользуемые хуки
  styles/              # глобальные стили
public/
docs/                  # spec.md, content-model.md, security-checklist.md
```

**Тулинг:** ESLint + Prettier, Husky pre-commit (typecheck + lint + format), commitlint (Conventional Commits), Vitest. Скрипты: `dev`, `build`, `start`, `lint`, `typecheck`, `format`, `test`.

## 8. Нефункциональные требования

- **Производительность:** Lighthouse 90+; `next/image` с размерами и приоритетом LCP; `next/font`; без CLS; ленивые сторонние виджеты (карты/отзывы/embed).
- **Доступность:** семантика, контраст, видимый фокус, полная клавиатура, осмысленные alt, aria где нужно, `prefers-reduced-motion`.
- **Адаптив:** проверка на 360 / 768 / 1280, мобайл-фёрст.
- **Состояния:** loading / error / empty на всех данных; кастомные 404/500.
- **Безопасность:** security-заголовки (CSP с whitelist VK/RuTube/Яндекс, HSTS, X-Content-Type-Options, X-Frame-Options/frame-ancestors, Referrer-Policy, Permissions-Policy); секреты только в `.env`; серверная валидация; анти-спам; `npm audit`.
- **152-ФЗ:** согласие на обработку ПД у форм; для боевого запуска ПД клиентов — на хостинге в РФ.

## 9. Открытые вопросы (нужно подтверждение владельца)

Блокируют наполнение контента, но **не** блокируют каркас/дизайн. До ответов используем плейсхолдеры, помеченные в контенте.

1. **Цены.** У основных услуг цен не было. Нужны реальные цены Чебоксар (или «от N ₽») по каждой услуге и по наборам ТО (масло/фильтры/операции/итог по тарифам Бюджет/Оптимум/Премиум). Цены с masloff.ru — московские, для нас только как образец формата.
2. **Адрес на Университетской** — `35Г` или `35А`? На старом сайте расходится. Нужно одно верное значение.
3. **Куда слать заявки** — email, Telegram-бот или оба? Нужны адрес почты и/или chat_id/бот-токен (в `.env`, не в репозиторий).
4. **Список авто для наборов ТО** — какие марки/модели показываем на старте (VW Polo, KIA Rio, Lada…?).
5. **Соцсети/канал** — подтвердить `t.me/masloplus` и `vk.com/masloplus21` как источники галереи; есть ли VK Видео/RuTube канал для видео-embed.
6. **Юр-данные** для подвала и JSON-LD: ООО/ИП, название, ИНН/ОГРН (если размещаем), юр-адрес.
