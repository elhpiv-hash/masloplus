# content-model.md — Модель контента сайта «Масло Плюс»

> Описывает **структуру данных** всего сайта. Реализация — в `src/content/*` (TS/JSON), валидация — через zod-схемы в `src/lib`.
> Принцип: контент **не хардкодится** в разметке; добавление услуги/набора/точки = правка данных, без правки компонентов.
> Единый источник NAP (адреса/телефоны/график/соцсети) — `content/site.ts`.

Легенда: 🔴 — данные под уточнение у владельца (см. [spec.md §9](./spec.md#9-открытые-вопросы-нужно-подтверждение-владельца)); значения ниже — из старого сайта или плейсхолдеры.

---

## 1. Общие принципы модели

- Каждый раздел контента — типизированный массив/объект + zod-схема (source of truth типов).
- Все цены — целые рубли (`number`), формат вывода — через утилиту (`1 450 ₽`).
- Все идентификаторы — `slug` (kebab-case), стабильные, для ключей/ссылок/переноса в форму.
- Тексты, которые приходят извне (TG/VK), **санитизируются** перед выводом.

## 3. Услуги (`content/services.ts`)

Плоский список услуг, сгруппированных по категориям. Цена может быть фиксированной или «от».

```
ServiceCategory { slug, title, icon }        // engine | filters | transmission | extra | network
Service {
  slug: string
  categorySlug: string
  title: string
  description?: string
  // Цена по варианту материалов; null → «уточняется»
  price: {
    network: number | { from: number } | null   // материалы сети
    client:  number | { from: number } | null    // материалы клиента
  }
  freeWorkWithNetwork?: boolean   // работа бесплатна при материалах сети
  inCalculator: boolean           // участвует ли в калькуляторе
}
```

### 3.1. Категории и услуги (структура; 🔴 все цены уточняются)

**Двигатель (`engine`)**

- Замена масла и масляного фильтра в ДВС
- Промывка ДВС (полнообъёмная)
- Замена масляного фильтра без замены масла
- Выставить уровень масла в ДВС

**Трансмиссия (`transmission`)**

- Замена масла в АКПП / МКПП / DSG / CVT / раздатке / Haldex / дифференциалах (частичная / аппаратная под давлением)

**Фильтры (`filters`)**

- Замена салонного фильтра
- Замена воздушного фильтра

**Доп. работы (`extra`)**

- ГУР (замена жидкости)
- Тормоза (жидкость/работы)
- Сцепление
- Мосты/дифференциалы

**Отдельные услуги сети (`network`)**

- Проточка тормозных дисков
- Аппаратная замена антифриза под давлением
- Аппаратная замена тормозной жидкости

> Образец формата цены (эталон, московский — НЕ наш): замена масла в ДВС — материалы сети 1450 ₽ / материалы клиента 1750 ₽; промывка — бесплатно при материалах сети. Наши цены 🔴 берём у владельца.

### 3.2. Калькулятор (логика — `lib`, тесты — Vitest)

```
CalcInput  { selectedServiceSlugs: string[], materials: "network" | "client" }
CalcResult { items: {slug, title, price}[], total: number }
```

Кейсы для тестов: базовый набор; пустой выбор (0 ₽); переключение материалов; услуга без цены («уточняется» — исключается из суммы с пометкой).

## 4. Готовые наборы ТО (`content/packs.ts`)

Модель: **авто → тарифы → состав**. Добавить авто = добавить объект, без правки кода.

```
CarPack {
  slug: string                 // "vw-polo-1-6-110"
  brand: string                // "Volkswagen"
  model: string                // "Polo"
  engine: string               // "1.6 110 л.с."
  years?: string               // "2015–2020"
  fillVolumeL: number          // заправочный объём, л
  badges?: ("best" | "dealer-warranty")[]  // «Лучший выбор» / «Сохранение гарантии дилера»
  tiers: Tier[]                // Бюджет / Оптимум / Премиум (2–3 шт.)
}

Tier {
  name: "Бюджет" | "Оптимум" | "Премиум"
  oil: string                  // "LUKOIL 5w40 Genesis Armotech"
  filters: {
    oil?: string               // масляный: "SCT"
    air?: string               // воздушный
    cabin?: string             // салонный
  }
  ops: {                       // цены операций; 0 → «бесплатно»
    oilChange?: number
    airFilter?: number
    cabinFilter?: number
  }
  totalPrice: number           // итоговая цена набора
}
```

### 4.1. Пример (со старого сайта, VW Polo — 🔴 проверить/дополнить до 3 тарифов)

```
VW Polo 1.6 110 л.с., объём 4.2 л
  Бюджет:  масло LUKOIL 5w40 Genesis Armotech, фильтр SCT,  замена ДВС бесплатно → 4650 ₽
  Премиум: масло Shell 5w40 Ultra,             фильтр MANN, замена ДВС бесплатно → 6400 ₽
  (тариф «Оптимум» — 🔴 добавить)
```

### 4.2. Стартовый список авто — 🔴 уточнить

Эталон показывает VW Polo, Skoda Rapid/Octavia, KIA Rio/K5/Ceed, Hyundai Solaris, Renault Logan/Duster, Chery/Geely/Haval и др. Для нас нужен реальный список ходовых у сети (напр. VW Polo, KIA Rio, Hyundai Solaris, Lada, Renault Logan). Каждому — тарифы и цены.

## 5. Галерея работ и видео (`content/gallery.ts` + серверная выборка)

Живой источник + запасной ручной список.

```
GalleryItem {
  id: string
  type: "photo" | "video"
  src: string                  // фото: URL картинки; видео: embed-URL (VK Видео/RuTube)
  provider?: "vk" | "rutube"   // для видео
  caption?: string             // санитизированная подпись
  publishedAt?: string         // ISO
  sourceUrl?: string           // ссылка на пост TG/VK
}
```

- **Источники:** Telegram-канал `t.me/masloplus`, VK `vk.com/masloplus21`. Выборка **серверная**; токены только в `.env`; клиенту не отдаются. Свежесть — ISR/`revalidate` (~1 час).
- **Видео-embed whitelist доменов:** VK Видео (`vk.com` / `vkvideo.ru`), RuTube (`rutube.ru`). YouTube — запрещён.
- **Fallback:** ручной массив `content/gallery` (инструкция в README).

## 7. Заявки/формы (`features/booking` + серверный роут)

Единая модель полезной нагрузки для всех форм (запись, «не нашли марку», расчёт).

```
BookingPayload {
  name: string
  phone: string                // нормализованный
  locationSlug?: string        // выбранная точка
  serviceSlugs?: string[]      // из калькулятора
  packSlug?: string            // из наборов
  comment?: string
  consent: true                // согласие 152-ФЗ — обязательно
  // анти-спам (не сохраняется/не логируется как ПД):
  honeypot?: ""                // должно быть пусто
  ts?: number                  // временная ловушка
  captchaToken?: string        // Яндекс SmartCaptcha (если включим)
}
```

- Валидация zod на клиенте и на сервере (одна схема в `lib`).
- Каналы доставки: **email и/или Telegram-бот** 🔴 (адрес/токены — в `.env`).
- **Запрещено:** ПД в URL/query и в логах; логируем только факт заявки без содержимого ПД.

## 8. Юридический контент

```
LegalPage { slug: "policy" | "soglashenie", title, updatedAt, bodyMdx }
```

- `/policy` — Политика обработки ПД (ссылка из чекбокса согласия у всех форм).
- `/soglashenie` — Пользовательское соглашение.
- 🔴 Тексты предоставляет владелец/юрист; до этого — типовой шаблон-заглушка с пометкой «черновик».
